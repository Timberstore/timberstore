# Farebný návrh – porovnanie pred/po

Pred: stabilná 0.6.1. Po: farebné preview 0.6.2. Layout a obsah zostávajú. Kliknutím na obrázok sa dá otvoriť plné rozlíšenie.

**Osobné údaje** sú statické vykreslenie zachyteného reálneho DOM s vypnutými skriptmi, pretože priame screenshotovanie živého checkoutu sa zasekávalo. Natívny prechod na tento krok bol úspešne otestovaný; objednávka sa neodoslala. Ostatné stránky sú screenshoty živého DOM. Sidebar je výrez reálnej kategórie.
