# v0.6.11 – Dokončenie košíka a checkoutu

Klient 16. 10. 2026 schválil preview `653d6f5172ae7f707082f0c922e6df5ed6bb75e3` vo vetve `preview/mobile-shipping-layout-20261015` a jeho povýšenie na nové stabilné vydanie. Funkčné zdroje zostávajú totožné so schváleným preview; mení sa číslo verzie, build, release dokumentácia a cieľ loadera v repozitári. v0.6.10 sa preskakuje, tag v0.6.9 zostáva zachovaný.

## Zmeny od v0.6.9

- Univerzálne mobilné rozloženie dopravy, kontaktný blok checkoutu, klikateľné tel/mailto, biele texty/šípky Emerald CTA a zjednotený tvar login tlačidla.
- Emerald #00C853 podľa následného výslovného zadania klienta; success background, firemná oranžová a béžové plochy zachované.
- Mobilný náhľad košíka: stabilná hlavička a päta, jediný scroll produktov, zámok pozadia a obnovenie pozície. Hlavná ikona/počet/cena navigujú do plného košíka, samostatná šípka výhradne otvára a zatvára náhľad.
- Spoločné odsadenie súčtu/dopravy/CTA a jemná linka nad SPOLU. Natívny stav dopravy zadarmo určuje oranžový/zelený progress a zelené zvýraznenie zadarmo.
- Odstránené prekrývanie mobilného loga s košíkom, opravené biele foregroundy oranžových sidebar kategórií a medzery kontaktov menu.
- Súvisiaci tovar: odstránené zbytočné čakanie/animácia visibility, zachovaná natívna pripravenosť ovládania. Produktový detail neukazuje nespracované Apollo rozloženie počas inicializácie.
- Opravená synchronizácia po AJAX nahradení celého košíka, aj pri odmietnutom skladovom množstve. Natívny spinner kryje len nedokončenú štruktúru; ceny, limity a výpočty zostávajú Shoptetu.
- Responzívny detail existujúcej objednávky v natívnom shadow root so zachovaním údajov, súčtov a formulárov.

## Overenie schváleného preview

Desktop 1440 a mobilné šírky 320/375/390/430 px. Reálne kliky/dotyky, URL košíka a zachovanie obsahu, prepínanie popupu a scroll. 35 živých zmien množstva pri troch produktoch vrátane SKU 50151, odmietnutia 4000 → 6000, plus/mínus a ručných vstupov. Bežné aj cold/pomalšie načítanie, doprava zadarmo oboma smermi a opakované AJAX aktualizácie bez odhaleného nespracovaného layoutu. Checkout kontrolovaný bez odoslania objednávky.

Dôkazy a presné hranice: [cart-flicker](../previews/cart-flicker.md), [cart-actions](../previews/cart-actions.md), [finálne opravy](../previews/cart-final.md), [checkout](../previews/checkout-rc3.md), [detail objednávky](../previews/order-detail-cart-followup.md). Chromium s mobilnou emuláciou, nie reálny iOS/Safari; PageSpeed, reálna platba a odoslanie objednávky neboli overené. Cache porovnanie používalo TLS-overujúci transport, nie browser disk-cache benchmark.

Pri stabilnom povýšení: lint/build, porovnanie funkčných zdrojov a CSS so schváleným SHA, overenie JS s normalizovaným číslom verzie, dostupnosť a zhoda CDN súborov a runtime smoke nového tagu. Limity zostávajú 21 KiB CSS a 30 KiB JS gzip.

## Publikovanie a aktivácia

Merge do main a GitHub release/tag poskytujú nemenný build. Samy neprepínajú živý Shoptet. Agent nemá prístup k Shoptet administrácii; loader v repozitári je pripravený na aktiváciu, posledná potvrdená produkcia je v0.6.9.

Preview stabilného tagu: https://www.timberstore.sk/?ts_preview=v0.6.11

Súbory:

- https://cdn.jsdelivr.net/gh/Timberstore/timberstore@v0.6.11/dist/timber.min.css
- https://cdn.jsdelivr.net/gh/Timberstore/timberstore@v0.6.11/dist/timber.min.js
- Verziovaný loader: [shoptet/loader.html](../../shoptet/loader.html).

Po overení CDN v **Vzhľad a obsah → Editor HTML kódu → Záhlavie** synchronizovať v existujúcom Timber loaderi jediný parameter podľa verziovaného súboru: `var PROD = 'v0.6.9';` → `var PROD = 'v0.6.11';`. Ostatný obsah záhlavia zachovať; nevkladať ďalší loader.

Otvoriť https://www.timberstore.sk/?ts_preview=off a v novej relácii overiť `TimberLoader.version` aj `Timber.version` = v0.6.11, `preview = false`, bez preview badge. Skontrolovať homepage, kategóriu/detail, košík a jeho AJAX, dopravu/platbu a osobné údaje bez odoslania objednávky. Potom zapísať skutočnú aktiváciu do ADMIN-CHANGES.md.

Rollback: v tom istom loaderi synchronizovať PROD späť na `v0.6.9`, vypnúť preview cookie a overiť načítanie starého tagu. Žiadne prepisovanie tagov ani reset histórie.
