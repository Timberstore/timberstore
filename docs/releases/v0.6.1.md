# v0.6.1 – Hlavička, prihlasovanie a košík

## Text pre GitHub release

Schválená verzia Timber Store pre Shoptet Apollo. Obsahuje finálne úpravy preview 0.5.7–0.6.1 nad stabilnou 0.5.6.

- Zjednotená trojpásová hlavička: servisná lišta, kompaktný hlavný riadok a existujúca kategóriová navigácia.
- Upravené kontakty, otváracie hodiny a sociálne odkazy, dominantné vyhľadávanie a ikona účtu.
- Prihlasovací popup má Timber farby, čitateľné registračné tlačidlo vo všetkých interakčných stavoch a jasné orámovanie otvorenej ikony účtu.
- Desktop košík sa otvára ako ukotvený popup; zachovaná natívna Apollo logika. Menšia otočná šípka, oddelený badge a cena.
- Mini-košík má prehľadné produktové riadky, vnútorný scroll, dostupný footer a poradie doprava → SPOLU → CTA.
- Pokojnejšie quantity ovládanie a natívne potvrdenie zmeny množstva s teplým povrchom a jemným oranžovým rámikom.
- Mobilný košík má čitateľné riadky, 44 px dotykové plochy a opravený riadok Súvisiaci tovar.
- Zachované natívne ceny, množstevné limity, formuláre a AJAX. Produktový grid, filtre a sidebar bez nových dizajnových úprav.
- Overené desktop šírky 1440/1280/1024/768 px a mobil 430/390/375 px, quantity AJAX, related add-to-cart, doprava zadarmo a dlhý košík. Lint a build prešli v pôvodných gzip limitoch.

Testovanie prebehlo v Chromium/touch emulácii; reálny Safari, prihlásenie zákazníka a dokončenie objednávky sa netestovali. Podrobnosti sú v docs/previews/v0.6.0.md a docs/previews/v0.6.1.md.

2. Vytvoriť nový tag **v0.6.1** (vrátane písmena v), Target **main** po schválenom merge.
3. Release title: **v0.6.1 – Hlavička, prihlasovanie a košík**.
4. Do Release notes vložiť text z predchádzajúcej sekcie. Označiť Latest, neoznačovať prerelease. Publikovať release. Nie je potrebné prikladať dist ako prílohu: jsDelivr číta súbory priamo z tagu.

## Zapnutie v Shoptete

1. Zálohovať aktuálny loader z HTML hlavičky a zapísať jeho pôvodný PROD tag.
2. V Shoptet administrácii otvoriť Vzhľad a obsah → Editor → HTML kód → Záhlavie. Nájsť existujúci Timber loader; ponechať ostatné kódy bez zmeny.
3. V existujúcom loaderi zmeniť iba hodnotu `var PROD` na `'v0.6.1'`. Ak je potrebná kópia celého loadera, schválený súbor je `shoptet/loader.html` v tagu. Existujúci loader nahradiť, nevkladať druhý.
4. Uložiť a otvoriť https://www.timberstore.sk/?ts_preview=off; overiť aj v anonymnom okne. Preview cookie by inak mohla stále načítavať starší commit namiesto produkčného tagu.
5. V konzole overiť `TimberLoader.version` = `v0.6.1`, `TimberLoader.preview` = false a `Timber.version` = `v0.6.1`.
6. Otestovať vyhľadávanie, login popup/registráciu, mini-košík, plus/minus, súčet a CTA, mobilný košík/Súvisiaci tovar a kategóriové filtre. Objednávku netreba dokončovať.
7. Nasadenie zapísať do ADMIN-CHANGES.md s dátumom, pôvodným PROD tagom a novým v0.6.1.

Rollback: v rovnakom loaderi vrátiť pôvodný PROD tag zo zálohy, uložiť a vypnúť preview cookie. Tag v0.6.1 neprepisovať.
