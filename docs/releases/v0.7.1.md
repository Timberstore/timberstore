# Timberstore v0.7.1 · 2026-10-27

Owner-authorized release of the tested site-wide loading stability fix. Publishing status and exact CDN hashes are recorded in this directory once verified. **Live Shoptet activation remains pending:** the public shop was observed using v0.7.0, and the available admin URL redirects to login. Publishing a GitHub tag alone does not change the live shop.

The release promotes `0.7.1-rc.0` to `0.7.1` without changing application behavior. Scope and complete test evidence: [loading stability](../fixes/loading-stability/README.md), [metadata](../fixes/product-metadata-loading/README.md). [Owner authorization](v0.7.1/OWNER-APPROVAL.md).

Retained budgets: JS 32 KiB / CSS 27.5 KiB gzip. Earlier release budgets and immutable tags are unchanged. Safari/WebKit, physical iPhone and PageSpeed were not tested for this release.

## Activation target

The versioned source [loader](../../shoptet/loader.html) targets v0.7.1 and restores the saved catalogue view before the bundle loads. It is derived from the observed live loader and retains its historical v0.6.5 compatibility guards. The [public pre-activation backup](../../shoptet/backup/2026-10-27/live-loader-before-v0.7.1.html) targets v0.7.0.

After CDN verification, install the prepared loader in Shoptet’s existing header-code slot, replacing that one existing Timber loader. Do not append a second copy. No other header integrations or body scripts need changing. Save the current admin value before editing.

A clean browser must report `TimberLoader.version === 'v0.7.1'`, `Timber.version === 'v0.7.1'`, `TimberLoader.preview === false`. Verify category controls, the reported spring detail, native cart update and the mini cart on mobile and desktop.

## Rollback

Restore the exact pre-activation loader backup, or change only `var PROD = 'v0.7.1';` back to `var PROD = 'v0.7.0';` in the prepared loader. The v0.7.0 tag/assets are not modified. Clear any preview cookie and verify `preview === false`.
