# Timberstore v0.7.5 · 2026-11-01

Majiteľ schválil prílohy aj kontaktný blok a výslovne požiadal o rovnaký postup stabilného vydania ako predtým. Aktiváciu v Shoptete vykoná sám. [Súhlas](v0.7.5/OWNER-APPROVAL.md).

## Zmeny od v0.7.4

- Súbory na stiahnutie: nový názov záložky vrátane mobilného prepínača a dynamického počtu, kompaktné plnošírkové riadky, SVG ikona dokumentu so zahnutým rohom, pravá ikona skutočnej akcie, jemný hover a klávesnicový focus. Menšie spodné odsadenie iba tejto záložky.
- Pôvodné názvy a URL príloh zostávajú zachované. Formát len z explicitných údajov/prípony; bez čítania dokumentov, odhadovania obsahu a bez zásahu do importu Mergado.
- „Sme tu pre vás“: spoločné otváracie hodiny a dynamický stav dostupnosti podľa Europe/Bratislava, e-mail a telefón v tomto poradí, spoločné ikony a kontaktné texty. Celý blok na stred, kontakty 15 px bold, podnadpis bold; pôvodné odkazy, rám, umiestnenie a breakpointy Apollo zachované.
- Opakovaná inicializácia a obnovenie obsahu bez duplicít; pozorovanie len príslušných komponentov.

## Overenie

Povýšenie schváleného kandidáta bez zmeny aplikácie: src nezmenené, CSS presná bajtová zhoda, JS sa líši len verziou. [Manifest](v0.7.5/assets.json). Stabilná verzia preberá existujúce limity JS 34.5 / CSS 31.5 KiB bez zvýšenia; staršie limity a tagy ostávajú zachované.

Lint, build, URL/formát/premenovanie a whitespace kontroly PASS. Predošlé presné CDN a Chromium dôkazy: [prílohy](../previews/product-downloads/POLISH.sk.md), [kontakty](../previews/sidebar-support/README.md). Fyzický iPhone/Safari a PageSpeed NOT TESTED.
